# Styles — the "how it looks" dial

green screen · ai avatar / recipe · transformation · skits

**Green screen vs AI avatar** — the difference is whether the character is *composited over* the
visual or *standing inside* it. Green screen = a cut-out talking head pinned over full-frame
B-roll, three channels (underlay / overlay / karaoke text), character goes full frame at the CTA.
AI avatar = the character in her own world, full frame, staged, real props in hand, no cut-out.
The staging is the difference.

⚠️ `transformation` names two different things in the legacy repo — a *hook* and a whole *format*.
Pick one meaning here and never reuse the word for the other.
